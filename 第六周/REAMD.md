第6周：闭环控制初探 课堂笔记
 一、开环 vs 闭环
- 开环控制：只发命令，不检查结果 → 简单、精度低
- 闭环控制：发命令 → 传感器测结果 → 算误差 → 调命令 → 精度高、能纠错

 二、PID 控制器（核心算法）
- 公式：输出 = 比例项 + 积分项 + 微分项
- 比例P：误差越大，调整力度越大 → 响应快
- 积分I：累计误差，消除长期偏差 → 稳准
- 微分D：看误差变化趋势，提前抑制 → 防震荡
- 用途：速度、位置、角度的精准控制

 三、避障逻辑
- 核心流程：读距离 → 判断是否小于安全值 → 是就停/退/转，否就直行
- 优化：对比左右距离，往空旷的一侧转，更合理
