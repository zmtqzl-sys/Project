第11周：Docker 进阶与 GitHub Pages 网页部署 课堂笔记
 Docker 进阶
- 查看容器：`docker ps` / `docker ps -a`
- 停止容器：`docker stop` / `docker kill`
- 保存镜像：`docker commit`，提交修改与备注
- 实操：运行容器 → 安装依赖 → 保存为新镜像

 GitHub Pages 部署
- 免费将仓库转为网页，推送即更新
- 开启：仓库设置 → Pages → 选择分支 → 保存
- 美化：配置 `_config.yml` 选主题
- 规范：按周次建目录，每个目录含 README，图片用相对路径
- 访问：`https://用户名.github.io/仓库名/`
