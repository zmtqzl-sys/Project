第7周：复习与实操演练 课堂笔记
 一、基础与环境（1-3周）
 核心概念
- **ROS2**：机器人操作系统，提供通信、工具、生态
- **节点 Node**：独立运行的程序单元，功能载体
- **话题 Topic**：节点间数据通道，**发布/订阅**模型通信
- **Twist 消息**：控制运动，`linear.x` 前后、`angular.z` 旋转
- **rclpy**：ROS2 的 Python 接口，写节点必用

 常用命令
- `ros2 run 包名 节点名` → 启动节点
- `ros2 node list` → 看运行节点
- `ros2 topic list` → 看所有话题
- `ros2 topic pub` → 发消息
- `ros2 topic echo` → 收消息

 编程要点
- 类继承 `Node`，在 `__init__` 里创建发布者/定时器
- 定时器绑定回调函数，循环执行任务
- 走正方形逻辑：直行 → 转90° → 重复4次

 二、运动与感知（4-6周）
 坐标系与里程计
- **世界坐标**：固定参考，绝对位置
- **机器人坐标**：以自身为中心，前方X、左方Y
- **里程计 Odometry**：靠轮子/IMU 估算位移与姿态，话题 `/odom`
- **运动学公式**
  - 线速度 `v = (左轮 + 右轮) ÷ 2`
  - 角速度 `ω = (右轮 - 左轮) ÷ 轮间距`

 传感器与可视化
- **外部传感器**：激光雷达（测距离/避障）、相机（看图像）
- **内部传感器**：里程计、IMU（测姿态）
- **RViz**：可视化工具，显示模型、雷达、图像、轨迹

 控制逻辑
- **开环**：只发命令，不检查 → 简单不准
- **闭环**：测结果 → 算误差 → 调命令 → 精准
- **PID 控制器**
  - P：按误差调大小 → 响应快
  - I：消长期偏差 → 更准确
  - D：抑快速波动 → 防震荡
- **避障**：读距离 → 小于阈值 → 停/退/转
