第二周 课堂笔记
 一、基础命令
 核心命令分类
- `ros2 pkg`：管理功能包
- `ros2 node`：管理运行节点
- `ros2 topic`：管理数据通信话题
- `ros2 service`：管理请求式服务
- `ros2 launch`：一键启动多节点
- `ros2 bag`：录制/回放数据

 常用命令
1. 节点操作
   - 查看运行节点：`ros2 node list`
   - 运行节点：`ros2 run 包名 节点名`（例：`ros2 run turtlesim turtlesim_node`）

2. 话题操作
   - 查看所有话题：`ros2 topic list`
   - 查看话题数据：`ros2 topic echo 话题名`
   - 发数据到话题：`ros2 topic pub 话题名 消息类型 "数据"`

3. 工作空间
   - 编译：`colcon build`
   - 环境生效：`source install/setup.bash`

二、核心概念
  节点
- 特点：独立进程、各干各的事、互不干扰；一个功能对应一个节点
- 生命周期：初始化 → 运行 → 销毁

 话题
- 作用：节点间异步传数据，发布者只管发，订阅者只管收
- 关键消息：`Twist`（控制速度）
  - `linear.x`：前进/后退速度（米/秒）
  - `angular.z`：旋转速度（弧度/秒），逆时针为正

 速度公式
- 圆周运动：`v = r × ω`（v=线速度，r=半径，ω=角速度）
- 推导：`r = v ÷ ω`、`ω = v ÷ r`

 速度控制表
| 动作 | linear.x | angular.z |
| :--- | :--- | :--- |
| 直行前进 | 1.0 | 0.0 |
| 直行后退 | -1.0 | 0.0 |
| 原地左转 | 0.0 | 1.0 |
| 原地右转 | 0.0 | -1.0 |
| 画圆 | 正数 | 正数/负数 |
| 停止 | 0.0 | 0.0 |
