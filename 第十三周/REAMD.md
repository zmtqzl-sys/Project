第 13 周：四足机器人入门 + 期末项目实施 课堂笔记


 核心问题：为何用腿不用轮？
- 轮子：平地快，复杂地形不行；
- 腿：慢但适应楼梯、山地等70%地球地形，适合救援、巡检；
- 4足最优：平衡、灵活、成本三者最佳平衡。

机器狗结构
- 4条腿：左前/右前/左后/右后；
- 每条腿3个关节，共12个自由度；
- 关键部件：IMU、编码器、足底传感器；
- 价格大降：从百万级到万元级，普及度高。

技术演进五阶段
1.  1960–80：纯机械，手动控制，走不动；
2.  1980–90：CPG仿生，自动出步态，适应差；
3.  1990–2000：ZMP理论，数学保稳定，走得慢；
4.  2005–15：MPC+全身控制，踹不倒、能跑跳；
5.  2018至今：强化学习，仿真自学，迁移到真机；
6.  最新：具身智能，大模型直接控制。

步态类型
- Walk：慢、稳，3条腿着地；
- Trot（常用）：对角腿同步，日常小跑；
- Bound：前后腿同步，跳跃；
- Gallop：高速冲刺，猎豹姿态。

PyBullet仿真
1.  安装：`pip install pybullet numpy`；
2.  核心步骤：连引擎→加载模型→设重力→循环步进；
3.  步态控制：生成关节角度→位置控制→循环更新；
4.  常见坑：初始冲击摔、关节号错、力矩不够、方向反。
