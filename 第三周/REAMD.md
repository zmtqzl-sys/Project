第三周 编程与控制 课堂笔记

 一、Python 基础
- 数据类型：整数、小数（速度常用）、文字、真假判断；列表存多个数据、字典存键值对
- 函数：封装重复代码，给参数就能出结果
- 类：把数据和功能放一起，ROS2 节点全靠它
- 控制：`if` 判断、`for`/`while` 循环，`break` 跳出、`continue` 跳过
- 模块：导入现成工具包，少写很多代码

 二、ROS2 Python 核心
- rclpy：ROS2 的 Python 接口，写程序必用
- 节点 Node：独立运行的程序单元，一个功能一个节点
- 发布者 Publisher：往话题发数据（比如速度指令）
- 定时器 Timer：定时执行任务，循环发指令靠它
- 消息 Twist：最常用，`linear.x` 管前后速度，`angular.z` 管旋转

 三、运动控制
- 基础动作：前进/后退改 `linear.x`，左转/右转改 `angular.z`，全零就停止
- 走正方形：直行 → 右转90° → 重复4次，回到起点
- 时间计算：直行时间 = 距离 ÷ 速度；转弯时间 = 1.57 ÷ 角速度（90°≈1.57弧度）

 四、仿真工具
- Turtlesim：2D 小乌龟，入门练命令、节点、话题超合适
- PyBullet：3D 仿真，纯 Python 开发，轻量易上手，快速验证算法

 五、自然语言控制（RosClaw+OpenClaw）
- 流程：发消息（如“前进1米”）→ AI 理解 → 自动转成 ROS2 指令 → 机器人执行
- 用途：用聊天软件就能控制，不用敲命令，方便又直观

 六、3D 运动
- 2D 只有前后左右旋转；3D 增加上下、抬头低头、翻滚，更接近真实机器人
